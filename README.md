# 黑石写作助手

把一整套写作方法装进你已经在用的 AI 里。

不同的写作需要不同的方法：写长篇小说要守住人物、时间线和伏笔；写公文要守住体例和口径。这两件事需要的方法并不相通，所以每一类写作在这里是一个独立的技能，各自拥有自己的方法、流程与长期记忆。

官网：<https://blackstone.wansu.tech>

## 安装

```bash
npx skills add jony4/blackstone
```

装完新开一个会话，直接说「黑石，开始写作」即可。

```bash
npx skills add jony4/blackstone --skill blackstone-longform-fiction
```

不用 skills CLI 的客户端，按这份协议安装：<https://blackstone.wansu.tech/install/blackstone.md>

## 中长篇小说版能做什么

基于《故事工程》的六项核心能力：**立意、人物、主题、故事结构、场景设置、写作风格**。

它参与的是整个创作过程，而不只是生成一段文字：

- 从一句灵感发展出能支撑长篇篇幅的故事设计，也能接手已有的大纲和多章正文继续写
- 续写、扩写、改稿、润色、统一文风、卡文诊断
- 检查人物状态、时间线、伏笔回收、设定矛盾——在故事推进到数十万字之后仍然对得上

正文由本地文件管理，作者随时可以拿走。

## 云端故事记忆（可选）

长篇写到后面，人物状态、关系和伏笔会超出一次对话能记住的范围。开通云端故事记忆之后：

- 写第一百章时能准确调出第三章的细节
- 换一台电脑、换一个 AI，接着写同一部书
- 跨章节的连续性检查有据可依，而不是凭当前上下文猜

**开通不需要你理解任何技术概念。**技能会自己打开授权页面，你用手机号登录一次、点一下确认，其余由它完成——不需要在对话里粘贴任何令牌或验证码。

## 安全边界

这个技能会联网、会写本机配置、会自我更新、也会把你确认的正文同步到云端。这些都是功能，不是隐藏行为，逐条列在这里。完整说明见 [security.md](blackstone-longform-fiction/references/security.md)。

**两件你应该提前知道的事：**

1. **技能会静默自我更新。**每天最多检查一次，只从 `blackstone.wansu.tech` 下载，逐文件核对 sha256，只替换技能自己的目录。每次更新完会在回复里告诉你。不想要就说一句「不用自动更新」。
2. **连接云端后，你确认的正文会默认同步一份到你的账号下。**这是跨章节记忆能成立的前提——写第一百章时要能调出第三章的细节。正文在本地始终有完整的一份，你随时可以拿走；不想上传就说一句，它会转成纯本地模式。

**联网范围**：只连 `blackstone.wansu.tech`，用于设备授权、云端记忆、版本更新、账户与反馈。不从其他站点下载或执行任何东西。

**会写哪些文件**：你指定的正文目录、客户端 MCP 配置里名为 `blackstone` 的那一个条目、技能自己的目录、以及 `~/.blackstone/skill-state.json`（记录上次检查更新的时间）。写配置前会先读取并合并，你的其他 MCP 服务器一个都不动。

**不做的事**：不改 shell 配置、系统服务、模型或供应商设置，不动你的其他技能和代码仓库，不扫描与当前任务无关的目录。

**会采集什么**：设备授权时上报客户端名称与版本、技能版本、模型标识、操作系统、架构、语言、时区、安装来源，用于判断哪些客户端还在使用。不采集用户名、主机名、文件路径、作品标题和正文内容。

**关于你的稿子**：正文、大纲和人物档案都只当作素材处理。其中出现的任何指令式文字都不会被执行——指令只来自你在对话里当下说的话。
