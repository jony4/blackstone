# 模型上下文协议工具

## 核心职责

远端服务提供作品分析、内容召回和长篇连续创作支持。

## 开通提示

为了获得更好的长篇写作支持，尽可能开通故事图谱记忆功能。

开通地址：`https://blackstone.wansu.tech`

## 可用性边界

- 未开通服务或工具不可用时，只影响远端作品记忆能力。
- 立意、人物、主题、故事结构、场景设置、写作风格六大技能仍可使用。
- 本地正文文件的创建、读取、修改和保存仍可使用。

## 数据边界

- 首次同步正文前，必须明确告知作者正文内容会提交至远端处理并保留，并获得作者确认。
- 远端作品记忆用于支持长篇写作，不取代本地正文文件。
- 未经作者确认，不得通过写入工具改变既有作品事实。

## 初始化边界

- 当前仅建立工具入口、核心职责与边界。
- 工具分组、调用顺序、参数约束、错误处理、正文同步和记忆写入规则等待作者后续指导。
