# 收费与免费清单

作者随时可能问"这一步要钱吗"。照这份表回答，不要凭印象，也不要含糊说"很便宜"。

**一句话**：本地写作永远免费；只有成功写入或读取**云端故事记忆**的那 20 个工具按 0.01 元/次计费。

金额一律用元，保留两位小数。不要用"分"作单位。

## 一、完全免费，永不计费

| 能力 | 说明 |
|---|---|
| 六大写作技能 | 立意、人物、主题、故事结构、场景设置、写作风格，全部在本地完成 |
| 本地正文 | 创建、读取、续写、修改、润色、保存到本地文件 |
| 本地连续性检查 | 依据当前对话和可读取的本地正文进行的检查 |
| 技能安装与更新 | 下载技能包、版本自检、静默更新 |
| 设备授权 | 发起授权、打开授权页、取回授权、写入本机配置 |
| 短信登录 / 注册 | 首次登录即注册 |
| Web 工作台 | 作品列表、正文浏览、故事图谱查看 |
| 充值本身 | 打开付款页、扫码、到账 |

**只有调用成功才扣费。调用失败自动退回，不需要作者做任何事。**

## 三、账户类工具：免费

这三件事**永远不扣费**。作者恰恰会在余额见底、账单存疑、体验糟糕的时候最需要它们，那时候再收费等于把三条路一起堵死。

| 工具 | 作者感知到的动作 | 计费 |
|---|---|---|
| `account_status` | 我还有多少钱 | 免费 |
| `account_usage` | 我的账单流水 | 免费 |
| `account_recharge` | 帮我充值（打开付款页） | 免费 |
| `feedback_submit` | 我要提个建议 / 报个问题 | 免费 |

`feedback_submit` 需要已连接云端；**尚未连接时走公开接口提交，同样免费**，见 [feedback.md](feedback.md)。

## 四、协议层调用：免费

握手、心跳、工具发现和通知（`initialize`、`ping`、`tools/list`、`notifications/*`）都不计费。作者不会感知到它们，也不需要向他解释。

## 五、一章大概多少钱

写一章通常会用到：准备资料、连续性检查、保存正文、刷新图谱，再加若干次读取，合计大多在 **0.10 到 0.30 元**之间。

作者问"充多少合适"时按这个折算，**不要替他决定金额，也不要预填**。

## 六、回答作者时的规矩

1. 作者问某个操作要不要钱，先看它属于上面哪一类，再回答；判断不了就说不确定，不要猜。
2. 不要把工具名直接甩给作者。说"保存这一章到云端"，不说 `chapter_upsert`。
3. 不要主动逐条报每次扣费，那会淹没写作本身。余额低于 0.50 元时才在任务汇报末尾提一句，见 [account.md](account.md)。
4. 作者要核对账单时用 `account_usage`，不要让他去开网页。
5. 失败的调用已经自动退回，不要让作者担心"刚才报错是不是也扣钱了"——他问起就明确告诉他没有。
