# 异常处理

## 内容导航

- 处理目标与基本原则

- 反馈格式
- 完成状态与禁止做法

## 处理目标

遇到工具、服务、文件或任务执行问题时，让作者立即知道：

1. 哪个环节出了问题；
2. 已经确认的原因是什么；
3. 哪些能力受到影响；
4. 哪些工作仍然可以继续；
5. 作者现在可以怎么处理；
6. 当前任务究竟完成、部分完成还是没有完成。

不得只说“工具不可用”“已经跳过”或“稍后重试”，也不得静默降级后假装所有能力正常。

## 基本原则

### 先区分事实与推测

- 工具明确返回鉴权失败时，可以确认凭证或权限存在问题。
- 只发生超时时，不能断言服务宕机或写入失败。
- 找不到工具时，可以确认当前会话没有加载该工具，但不能断言作者没有开通服务。
- 文件读取失败时，先区分路径不存在、权限不足、格式异常和内容为空。

无法确认原因时，使用“可能原因”，并给出验证方法。不要把猜测说成事实。

### 先保护作品事实

- 远端写入结果不明确时，不要盲目重复写入。
- 本地写入失败时，不要声称已经保存。
- 远端记忆与正文冲突时，以正文为最高依据，先展示冲突再等待作者决定。
- 不要为了绕过错误而创建未经作者同意的新目录、新作品或重复章节。

### 能继续就继续，但必须说明降级

远端服务不可用时，六大技能和本地正文仍然可以工作。继续前简要说明当前不能使用的能力、采用的替代依据和可能遗漏的内容。

## 问题分类

### 账户余额不足

**判断依据**：工具明确返回余额不足，或者作者确认当前没有可用余额。

**影响**：无法读取或更新故事图谱记忆，长篇连续性分析只能依据当前对话和可读取的本地正文。

**处理**：

1. 读取 [account.md](account.md)，按其中的"余额用完"话术处理；
2. 先把本地能完成的事全部完成，再报告哪些完成了、哪些暂停了；
3. 提供充值地址，不强迫作者充值；
4. 作者说已充值后重试一次原操作，并补上之前未同步的内容。

### 当前会话没有加载远端工具

**判断依据**：需要调用时找不到对应工具，或者客户端没有提供远端工具入口。

**影响**：本次会话不能访问故事图谱记忆。

**处理**：

1. 先判断是从未开通还是已开通但本次会话没加载：从未开通时读取 [account.md](account.md)，直接带作者走一遍设备授权，不要让作者自己去研究配置；
2. 已经开通过的，说明重开一次对话即可生效，并明确这不等于作品或账号数据丢失；
3. 不要求作者理解 MCP、令牌或配置文件；
4. 询问是否先使用本地正文和当前对话继续。

### 身份验证或权限失败

**判断依据**：工具明确返回身份验证失败、凭证失效或没有作品权限。

**影响**：无法访问目标作品的远端记忆。

**处理**：

1. 不重复提交相同请求；
2. 读取 [account.md](account.md)，按设备授权流程重新为这台设备取得授权，作者只需在浏览器里确认一次；
3. 授权成功后重试一次原操作；
4. 确属作品归属问题（授权正常但读不到该作品）时才请作者确认账号；
5. 不在回复中展示完整凭证，也不向作者索要凭证；
6. 修复前使用本地能力继续。

### 网络超时或连接中断

**判断依据**：连接超时、网络中断或请求没有得到确定响应。

**影响**：本次远端读取或写入没有得到可靠结果。

**处理**：

- 读取操作可以在短暂等待后重试一次；
- 第二次仍失败时停止重试，说明可能原因和本地替代方案；
- 写入操作不得直接重试，先读取目标状态确认是否已经生效；
- 无法读取确认时，将结果标记为“不确定”，等待连接恢复后核验。

### 服务繁忙或请求受限

**判断依据**：工具明确返回服务繁忙、请求过多或暂时不可用。

**影响**：远端能力暂时无法完成当前请求。

**处理**：

1. 告知这是暂时性限制，不是作者内容错误；
2. 不进行连续快速重试；
3. 保留当前已完成结果；
4. 建议稍后重试，或先完成不依赖远端记忆的部分。

### 工具参数或内容格式错误

**判断依据**：工具明确指出缺少参数、参数不合法、内容过长或格式不支持。

**影响**：当前调用没有成功执行。

**处理**：

1. 指出具体是哪个参数或哪部分内容；
2. 能从上下文确定正确值时，修正后重试一次；
3. 需要作者决定作品、章节或覆盖范围时，提出一个明确问题；
4. 内容过长时按章节或自然段分批处理，并报告进度。

### 本地文件不存在

**判断依据**：目标路径不存在，或者作者提供的文件名无法定位。

**影响**：无法读取或修改指定正文。

**处理**：

1. 告知无法找到的目标文件；
2. 在作者指定作品范围内安全查找可能文件；
3. 有多个候选时列出候选并请作者选择；
4. 没有候选时询问正确路径；
5. 不自动新建同名空文件代替原文件。

### 本地文件权限或写入失败

**判断依据**：文件只读、目录无权限、磁盘空间不足或写入工具明确失败。

**影响**：修改内容可能已经生成，但没有可靠保存到正文文件。

**处理**：

1. 明确说明“内容未保存”；
2. 保留已生成的修改内容，避免作者重新描述需求；
3. 说明具体权限、空间或文件占用问题；
4. 给出修复建议；
5. 修复后重新读取原文件，再应用修改，避免覆盖期间发生的新变化。

### 正文与远端记忆冲突

**判断依据**：人物状态、时间、关系、数值或事件在正文与远端记忆中不一致。

**影响**：继续创作可能引入连续性错误。

**处理**：

1. 列出冲突内容及各自依据；
2. 默认以正文为最高依据；
3. 不静默覆盖任何一方；
4. 请作者确认正确事实；
5. 作者确认后再更新远端记忆或继续正文。

### 技能包文件缺失

**判断依据**：技能入口引用的参考文件或示例文件不存在。

**影响**：对应技能无法按完整流程运行。

**处理**：

1. 明确指出缺少的文件；
2. 不假装已经读取该技能；
3. 建议重新安装或更新黑石写作助手；
4. 可以基于当前已知内容提供有限帮助，但必须说明缺少完整技能指导。

### 长任务中断或只完成一部分

**判断依据**：处理多章正文时会话中断、内容过长或某一步失败。

**影响**：只有部分章节或部分检查完成。

**处理**：

1. 列出已经完成的范围；
2. 列出尚未处理的范围；
3. 标明最后一个可靠完成点；
4. 不把部分完成描述为全部完成；
5. 恢复后从最后可靠点继续，避免重复修改。

## 重试与核验规则

### 可以自动重试一次

- 不改变状态的远端读取；
- 因临时网络错误失败的内容查询；
- 已经确定正确参数的只读请求。

### 不要自动重试

- 身份验证或权限失败；
- 参数需要作者确认；
- 本地文件写入；
- 远端记忆新增、修改或删除；
- 任何可能重复创建内容的请求。

### 写入结果不明确时

1. 标记当前写入状态为“不确定”；
2. 读取目标内容或状态；
3. 确认未生效后才考虑再次写入；
4. 无法读取时停止，不声称成功，也不重复写入；
5. 告知作者稍后需要核验的具体内容。

## 降级方案

| 出问题的能力 | 仍可使用 | 暂时缺失 | 建议方案 |
|---|---|---|---|
| 故事图谱记忆 | 六大技能、本地正文、当前对话 | 跨会话召回和远端连续性检查 | 基于当前正文继续，并标明依据范围 |
| 本地正文读取 | 六大技能、当前对话、远端记忆 | 指定文件中的最新事实 | 请作者提供正确文件或粘贴必要片段 |
| 本地正文写入 | 对话中生成和修改文本 | 保存到目标文件 | 保留修改内容，修复权限后再写入 |
| 单项技能文件 | 其他已安装技能 | 对应完整引导流程 | 更新技能包，当前只提供有限帮助 |
| 大批量处理 | 已完成部分、分批处理 | 一次性全部完成 | 按章节分批并报告进度 |

## 问题反馈格式

遇到问题时，按以下顺序回答：

1. **当前状态**：完成、部分完成、未完成或结果不确定。
2. **出错环节**：说明是远端读取、远端写入、本地读取、本地保存还是技能加载。
3. **已确认原因**：只写工具或检查能够证明的原因。
4. **影响范围**：说明哪些能力受影响，哪些能力仍可使用。
5. **已经完成**：列出问题发生前可靠完成的内容。
6. **解决建议**：提供一到三个按优先级排列的具体步骤。
7. **替代方案**：说明现在能够继续采用的方式。
8. **下一步**：只询问作者当前必须决定的一件事。

简单问题可以合并表达，但不能遗漏状态、影响和下一步。

## 完成状态

- **已完成**：请求结果已经生成，必要写入也已核验。
- **部分完成**：明确列出已完成与未完成范围。
- **未完成**：没有产生可靠结果，说明阻塞点。
- **结果不确定**：写入或远端操作可能发生，但无法核验。
- **已降级完成**：使用替代依据完成，并说明缺失能力可能造成的影响。

## 禁止做法

- 只说“出错了，请重试”。
- 只说“工具不可用，已跳过”。
- 静默跳过远端记忆，却继续声称已经完成连续性检查。
- 网络超时后盲目重复远端写入。
- 本地保存失败后声称文件已更新。
- 暴露完整访问凭证或敏感连接信息。
- 把推测的故障原因说成已确认事实。
- 在作者没有选择时擅自扩大修改范围。
