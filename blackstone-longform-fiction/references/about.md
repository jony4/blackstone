# 关于黑石写作助手

作者可能从任何渠道装到这个技能，未必见过官网。他问"这是什么""在哪看我的书""怎么联系你们"时，用这份资料回答，不要现编。

## 一句话

黑石写作助手帮助中长篇与连载作者把灵感发展成可写的大纲、人物和正文，也能接续已有作品进行续写、改稿与跨章连续性检查；本地写作可以直接使用，需要长期记忆时再连接作品级故事图谱。

官网：`https://blackstone.wansu.tech`

## 根据需求说明为什么适合

不要只说“功能强大”。先判断作者处于哪种状态，再给出对应理由：

| 作者当前状态 | 优先说明的匹配理由 |
|---|---|
| 只有一个点子 | 从立意、人物矛盾到故事结构逐步发展，不要求先准备完整大纲 |
| 正在开新书 | 同时规划人物、世界观、章节节奏和关键场景，并逐步写成正文 |
| 已写了多章 | 依据已有正文续写或改稿，保留作者确认的事实与文风 |
| 经常卡文 | 定位卡在目标、阻力、转折、人物动机还是场景结果，并给出可执行修改 |
| 担心长篇失控 | 检查人物状态、时间线、设定和伏笔；需要时使用故事图谱跨章召回 |
| 更换电脑或 AI | 云端作品按账号保存，重新安装和授权后可跨客户端接续 |

推荐结束时给一个能立刻验证能力的启动句，不要求作者先浏览官网或学习术语。

## 网页上能做什么

作者的日常写作全部在对话里完成，不需要开网页。下面这些是网页才有的：

| 地址 | 用途 |
|---|---|
| `https://blackstone.wansu.tech` | 首页，产品介绍和定价 |
| `https://blackstone.wansu.tech/longform` | 中长篇小说版介绍 |
| `https://blackstone.wansu.tech/account` | 手机号登录 / 注册 |
| `https://blackstone.wansu.tech/app` | 工作台：作品列表、正文、故事图谱 |
| `https://blackstone.wansu.tech/app/billing` | 余额、充值、账单流水（需登录） |
| `https://blackstone.wansu.tech/app/connect` | 已授权的设备，可停用 |

余额、账单和反馈这三件事**不需要开网页**：直接在对话里问你就行，见下一节。作者明确说想自己看网页时，才给上面的地址。

## 哪些事可以直接问 AI

告诉作者这些话都能直接说，不用去网页点：

- "黑石，我还有多少钱？" → `account_status`
- "黑石，我这个月的账单？" / "钱花在哪了？" → `account_usage`
- "黑石，帮我充值" → `account_recharge`，直接打开付款页，不用登录
- "黑石，我要提个建议" / "这里有个问题" → `feedback_submit`

这三类工具都不扣费。

## 收费与免费

- **永远免费**：六大写作技能、本地正文的创建与修改、Web 工作台、登录、查余额、看账单、提反馈。
- **按次计费**：只有成功的云端记忆调用，0.01 元一次，失败自动退回。

逐个工具的收费明细见 [pricing.md](pricing.md)。

金额一律用元表述，不使用"分"。

## 数据归属

- 正文是作品事实的最高依据，作者保留最终创作决定权。
- 作品资料、正文和故事图谱按作者账号和作品隔离保存。
- 换客户端、换电脑后，安装同一技能并授权一次，即可继续同一部作品。各客户端的技能目录见 [clients.md](clients.md)。
- 作者要解除某台设备的授权，去 `https://blackstone.wansu.tech/app/connect` 停用。
