# 1.3.1

黑石写作助手·中长篇小说版的当前版本号。

这个文件由程序读取：服务端的下发接口和已安装技能的版本自检都以它为唯一依据。
解析方式是取文件里第一个形如 `x.y.z` 的数字，所以上面的标题必须是版本号本身。

改动技能内容时必须同时提升这里的版本号，否则已经安装的客户端会认为自己已是
最新，永远拉不到改动——而线上一切正常，没有任何迹象提示你漏了这一步。

同一个版本号还有两处副本，改这里时必须一起改，否则外部目录站会把技能标成
一个谁都没见过的版本：

- `SKILL.md` frontmatter 的 `version` 字段——SkillHub、clawhub 这类目录站只读
  SKILL.md，读不到就按 `0.1.0` 兜底展示；
- 独立技能仓库 `github.com/jony4/blackstone` 的 `v<版本号>` tag 与 release。
