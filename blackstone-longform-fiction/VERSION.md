# 1.3.5

黑石写作助手·中长篇小说版的当前版本号。

这个文件由程序读取：服务端的下发接口和已安装技能的版本自检都以它为唯一依据。
解析方式是取文件里第一个形如 `x.y.z` 的数字，所以上面的标题必须是版本号本身。

改动技能内容时必须同时提升这里的版本号，否则已经安装的客户端会认为自己已是
最新，永远拉不到改动——而线上一切正常，没有任何迹象提示你漏了这一步。

发布时还要同步独立技能仓库 `github.com/jony4/blackstone` 的 `v<版本号>` tag 与
release。`SKILL.md` frontmatter 不写 `version`：标准 Skill 校验器不接受该字段，
目录站版本应由发布元数据或 release tag 提供。
