# 激活与基础云端文件

## 边界

本地创作与云端文件是两个独立环节。只有作者明确要求激活、上传、下载、跨设备取回、余额、账单、充值或反馈时才进入本流程。

连接账号不代表同意上传。默认 `cloud_sync_mode` 为 `ask`；每次发送或取回作品内容前说明文件、章节或资料范围，取得明确确认。只有作者明确选择 `auto` 后，才可自动同步他已经确认的正文和资料。

短故事版的云端范围不包含 `graph_*` 工具。

## 激活

发起设备授权时使用：

```json
{"client_name":"<客户端与设备>","edition":"short-fiction","client":{"client":"<客户端>","skill_version":"<VERSION.md 版本>"}}
```

向 `POST https://blackstone.wansu.tech/api/pairing/start` 发起授权，打开返回的 `verify_url`，让作者在浏览器登录并确认，再用 `poll_secret` 调用 `/api/pairing/claim` 取回授权。不得显示、记录或要求作者粘贴 Token、验证码或密码。

WorkBuddy 可在作者同意后把服务端返回的 `mcp_config` 按键合并到已有 MCP 配置；不覆盖其他设置。其他客户端引导作者到 `https://blackstone.wansu.tech/app/connect` 手工粘贴一次完整配置。配置完成后提示新开会话。

## 允许的云端动作

仅在作者确认后使用下列基础能力，并始终传入 `edition: short-fiction`：

- 作品：列出、创建、读取和更新作品；
- 分卷：列出、新建或改名；短故事通常只需一个默认分卷；
- 章节：列出、上传、下载和更新正文；
- 六项资料：列出、读取和保存立意、人物、主题、结构、场景与风格；
- 账户：余额、账单、充值与反馈。

上传后回读并核对标题、字数或内容哈希；下载前确认目标本地文件，遇到同名文件不得静默覆盖。基础云端调用的实际价格以服务端和官网当前说明为准，不凭记忆报价。

## 降级

未激活、作者拒绝上传、余额不足或远端失败时，继续本地写作，并明确标记“仅本地”。不得声称内容已上传、已取回或已跨设备同步。
